# ===========================================================================
#  Rewrite rules - stage 2 of the filter
# ===========================================================================
#      pattern => replacement
#
#  Both sides are lowercased and split into words on load. An empty replacement
#  deletes the pattern. Longer patterns are tried first.
#
#  ---------------------------------------------------------------------------
#  When to add a rule here instead of a hotword
#  ---------------------------------------------------------------------------
#  Contextual biasing (stage 1) works inside the decoder, so it can only promote
#  token sequences the model is capable of emitting. Some substitutions survive
#  it anyway: if a speaker's "guest" genuinely sounds like "gas", the decoder may
#  keep choosing "gas" even with GUEST NETWORK boosted.
#
#  So the order to try things is:
#
#    1. Add the phrase to config/hotwords.txt. Fixing it in the decoder is
#       strictly better - it changes the hypothesis rather than patching the
#       output, and it generalises to nearby phrasings. (The boost is global, so
#       raise asr.hotwords_score only if a lot of phrases are underperforming;
#       raising it for one is how you get hallucinations on the others.)
#    2. If it still comes out wrong the same way twice, add a rule here.
#
#  A rule is SURGICAL: it repairs one specific observed substitution. Resist the
#  temptation to make it general. The tempting alternative - a fuzzy
#  nearest-neighbour pass over the whole transcript - fixes the case you were
#  looking at and quietly corrupts words you were not.
#
#  Keep the table acyclic: "a => b" alongside "b => a" would fight. Application
#  is capped at four passes so a cycle terminates instead of hanging, but the
#  result would be arbitrary.
#
#  The dashboard shows which rules fired on each utterance, so a rule that never
#  fires is visible and can be deleted.
# ===========================================================================

#     word; it says nothing about the Vietnamese/Indian accent case. Rules found

#
#  Every one of these survived biasing at boost 2.0 through 6.0 -- raising the
#  boost did not fix them and at 8.0 it broke two other clips. They are stage-1
#  misses, not stage-1 undertuning.
