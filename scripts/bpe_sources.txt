# Where to get bpe.model for models whose tarball does not ship one.
#
#   <sha1 of the model's tokens.txt>   <url of a matching bpe.model>
#
# Keying on the tokens.txt hash is the safe way to do this: a bpe.model is only
# usable with the exact token inventory it was trained with, and several
# sherpa-onnx English models share the LibriSpeech BPE-500 vocabulary while only
# some of the published tarballs actually contain bpe.model.
#
# Why we need it at all: sherpa-onnx encodes hotwords with its own
# sentencepiece encoder (modeling_unit=bpe + bpe_vocab=bpe.vocab). Without it
# the only available modeling_unit is "cjkchar", which splits English words into
# single letters -- those never line up with the decoder's subword output, so
# contextual biasing silently stops working.
